# Reader submissions

Reader stories for the "From the shamba" section.

**This repository is public**, so anything saved here can be read by anyone on GitHub, even after it is deleted
(git keeps the history). The folder is not published on the website, but it is still visible on GitHub. So:

- Keep the full submission (with the reader's phone or email) in your inbox. **Never save contact details here.**
- Save a story here only once the reader has agreed to it being published. Save it as `YYYY-MM-DD-<name>.md`
  with the story text, the name and area exactly as the reader agreed to be shown (or "name withheld"),
  and a photo only if they sent it for publication.

The Wednesday draft picks the newest unused one and notes in the pull request which file it used. Move used files into `submissions/used/`.
